Política de Privacidade

Esta página explica de forma simples como os dados enviados pelo site podem ser tratados pela Ronaldo Tecnologia.

1. Dados enviados pelo visitante

O site pode solicitar informações como nome, empresa, interesse e mensagem para facilitar o atendimento comercial. Quando o formulário de contato é utilizado, a mensagem é encaminhada pelo próprio visitante via WhatsApp.

2. Finalidade

Os dados são utilizados para responder solicitações, apresentar serviços, preparar propostas e manter comunicação relacionada ao atendimento solicitado.

3. Compartilhamento

A Ronaldo Tecnologia não comercializa dados pessoais. Informações podem transitar por serviços utilizados para comunicação e hospedagem, como WhatsApp, e-mail e infraestrutura do GitHub Pages.

4. Cookies e métricas

Esta versão do site não instala ferramentas de publicidade por padrão. Caso ferramentas de análise sejam adicionadas futuramente, esta política deverá ser atualizada.

5. Contato

Para dúvidas sobre privacidade, entre em contato pelo e-mail ronaldo@ronaldotecnologia.com.br.
